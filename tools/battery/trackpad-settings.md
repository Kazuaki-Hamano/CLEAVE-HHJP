# タッチパッド設定

左右の対応ファームウェアと、新しい`CLEAVE-Battery.exe`を使用します。
左側をUSB接続し、トレイアイコンを右クリックして「タッチパッド設定」を開きます。
右側は通常どおり電源を入れ、左右を接続してください。

| 項目 | 範囲 | 初期値 | 意味 |
|---|---|---|---|
| 基本速度 | 0.25～8倍 | 2倍 | 加速前の移動倍率 |
| 加速の強さ | 0～300% | 0% | 指の速さに対する追加倍率。0で加速なし |
| 加速の最大倍率 | 1～8倍 | 3倍 | 加速部分の上限。基本速度には別に掛かる |
| 検出感度 | 1x/2x/3x/4x | 1x | センサーのADC設定。カーソル速度の倍率ではない |

変更は約0.2秒の待ち時間の後に反映されます。基本速度・加速は左側に即時反映し、検出感度は暗号化済みの左右間BLEで転送され、通常数秒以内に反映結果を確認します。感度変更時にはセンサーを再調整するため、短い入力の中断があり得ます。

「反映済み」を確認し、「キーボードに保存」を押すと左側の不揮発設定へ保存します。調整中はフラッシュへ書き込みません。未保存の変更は左側の再起動で失われます。保存済みの検出感度は右側の起動・再接続後にも再適用します。保存成功は書き込み処理完了後に表示し、センサーが未反映・未接続なら保存ボタンを無効にします。

USBで設定した値は、PCとのBluetooth接続でもカーソル処理に使われます。ただし設定アプリからの変更は左側USB接続が必要です。Windowsのマウス速度は変更しません。

Fn（LANG2長押し・左右の専用Fn）中は縦スクロール専用です。カーソル速度と加速をスクロールには適用せず、移動量の-1/16をホイール値へ変換します。タップの左右クリックは維持します。Mouseレイヤーは削除され、旧LANG1位置は通常のINT4キーです。Studioで配置を保存している場合は、更新後にRestore Stock Settingsで新しい初期配置を反映します。

## 実装と通信

左側のUSB vendor HID Feature Report 7（ID込み32バイト）を使用します。既存レポート1～6と最大バッファ長は維持します。

- SET: `[7, 1, command, 0, speed_u16, acceleration_u16, maximum_u16, sensitivity_u8, zero...]`。整数はlittle-endian、倍率は百分率。commandは0=RAM反映、1=反映して保存。
- GET: `[7, 1, flags, 0, speed_u16, acceleration_u16, maximum_u16, desired_u8, applied_u8, sensor_error_i8, save_error_i8, generation_u16, diagnostics...]`。
- flags: bit0=保存値との差分あり、bit1=右側の感度反映確認済み、bit2=保存処理中。右側の結果は最終取得から5秒で失効します。
- 設定保存キー: `cleave_trackpad/config`。バージョン1と7バイトの設定値を保存。
- 左右間の感度指定: ZMK標準のbehavior転送で右側の`tp_sens`へ感度1～4を約1秒間隔で送ります。右側はセンサー変更処理後、標準input-split 0のMSCイベント（code=`0xc1e0`、上位16bit=`0x5450`、次の8bit=符号付きエラー、下位8bit=適用感度）で結果を返します。このイベントは軸・ボタン操作ではなく、syncも付けません。Fn中でも結果を確認できます。
- 旧GATTサービス`b6f4a630-3790-4c3c-934d-911d84233b10`と値`b6f4a631-3790-4c3c-934d-911d84233b10`は互換用に残していますが、感度の定期取得には使いません。

診断情報はbyte16が1の場合に有効です。byte17=通信段階、18=暗号化レベル（旧方式のみ）、19=ATTエラー（旧方式のみ）、20～21=送信APIの戻り値（符号付きLE16）、22=応答長、24～25=試行回数、26～27=応答回数です。通信段階は0=未接続、3=送信エラー、8=標準split転送後の応答待ち、9=標準splitで結果受信済みです。旧方式の1～7もアプリで読み取れます。byte16が0の旧版でも基本設定の形式は同じです。

GATTのバッファ確保は待機する可能性があるため、充電状態・更新情報の定期取得は専用の`cleave_peer_work_q`で実行します。感度指定はGATT読み取りを直接行わず、ZMKの標準送信キューへ渡します。

速度は各パケットのX/Yからユークリッド距離を整数で計算し、経過時間で「10ms当たりの移動量」に正規化します。直近速度を平滑化し、次のパケットの両軸に同じ倍率を適用します。加速倍率（百分率）は`min(最大倍率, 100 + 加速の強さ × 速度 / 10)`。最終倍率は基本速度との積です。150ms以上入力が途切れたら加速履歴をリセットし、小数の移動量は端数を蓄積します。

センサードライバーは`src/pinnacle/`に固定版から取り込みました。出典と変更点は[UPSTREAM.md](../../src/pinnacle/UPSTREAM.md)を参照してください。感度変更とパケット取得は同じwork queueで直列化し、再調整のポーリングにはタイムアウトを設けています。

ビルド・ソフトウェアテストと、実機での反映・再起動後の保持は別の確認です。最初に速度を変更して動作を確認し、その後に加速・検出感度・保存を順に試してください。
