# TM040040タッチパッド取り付けガイド

[ビルドガイドの目次](README.md) / [カスタマイズガイド](05-CUSTOMIZE.md)

CLEAVE HHJPにCirque Pinnacle **TM040040-2024-302**を後付けする手順です。このフォークで追加したカスタマイズで、標準キットの組み立てには必須ではありません。型番はTM040040です。

対象はXIAO nRF52840 Plusを搭載した構成です。パッドのランドとXIAO表面の追加GPIOランドを直接配線し、SPIで接続します。FFCケーブルや変換基板は使用しません。

写真は後日追加予定です。取り付け位置・固定具・配線の取り回しは使用するケースに合わせて決めてください。この手順は特定のケースへの収まりを保証するものではありません。

## 1. 完成後にできること

| パッド | 通常時 | Fnを押している間 |
|---|---|---|
| 右 | カーソル移動 | カーソル移動（クリックキーと併用可能） |
| 左 | 縦横スクロール | 左スワイプで戻る、右スワイプで進む |

タップによる左クリックと、端の領域での右クリックを有効にしています。今回の取り付け方向では、右パッドの右下端で右クリックになることを確認しています。領域の位置はパッドの取り付け方向によって変わります。

Fnは左右の専用Fnキー、左の旧LANG2位置の200ms長押し、右Space直後の旧LANG1位置の200ms長押しで有効になります。短押しはそれぞれINT5・INT4です。隣の独立したKanaキーはLANG1のままです。

戻る／進むは対応するブラウザーやアプリで使用できます。左スワイプは一定の横移動で1回発動し、一度動きを止めるかFnを押し直すと次を受け付けます。

左右パッドの通常動作、右のタップクリック、設定の反映・保存・再起動後の保持は実機確認済みです。左のスクロール・Fnスワイプと旧LANG1長押しFnはビルド・生成設定・処理の検証済みですが、個別の実機確認結果はまだ記録していません。

## 2. 用意するもの

| 部品・工具 | 用途 |
|---|---|
| TM040040-2024-302 | 取り付ける側につき1個。左右に取り付ける場合は2個 |
| 細い被覆電線 | パッド1個につき7本。長さは仮置き後に決定 |
| はんだごて、はんだ、フラックス | パッドとXIAOのランドへの配線 |
| ピンセット、被覆剥き工具、拡大鏡など | 小さいランドの作業・確認 |
| テスター | 配線先、導通、隣接ランドの短絡確認 |
| 絶縁材、固定具 | 基板裏面の接触防止とケーブルの引っ張り防止 |
| データ通信対応USBケーブル、PC | ファームウェア書き込みと設定 |

右用の配線色は黒・茶・赤・橙・黄・緑・青、左用は黒・白・灰・紫・青・緑・黄です。色は今回の配線を識別するための約束です。最終的には色ではなく接続先の信号名を確認します。

## 3. 取り付け位置を仮決めする

1. キーボードが通常のキー入力と左右接続に問題なく使えることを確認します。
2. パッドを操作しやすい位置へ仮置きし、キーや手、ケースと干渉しないか確認します。
3. パッドの回転方向を決めます。向きを後で変える場合は、カーソル・スクロール方向と右クリック領域も再確認します。
4. 基板裏面と端子が他の基板・金属に触れない固定方法を決めます。ケーブルには少し余裕を持たせ、ランドに引っ張る力が掛からないようにします。

最終固定は配線と動作確認の後に行います。取り付け方向が既存の設定と異なる場合、軸の反転や回転にはファームウェアの変更が必要です。設定アプリから向きは変更できません。

## 4. 配線先を確認する

左右とも同じ信号・GPIOを使います。右のパッドは右XIAO、左のパッドは左XIAOへ接続します。

| パッドのランド | XIAO端子 | GPIO | 右側の色 | 左側の色 |
|---|---|---|---|---|
| GND | GND | — | 黒 | 黒 |
| VDD | 3V3 | — | 赤 | 白 |
| SS / CS | D11 | P0.15 | 茶 | 灰 |
| DR | D12 | P0.19 | 橙 | 紫 |
| SCK | D17 | P1.03 | 黄 | 黄 |
| SO / MISO | D18 | P1.05 | 緑 | 緑 |
| SI / MOSI | D19 | P1.07 | 青 | 青 |

VDDはXIAOの**3V3**へ接続します。5V/VBUSやBAT+には接続しません。SPI構成のR1は外しません。B1・B2・B3、SCL・SDA、FFCコネクタは今回使用しません。

USB端子を上、XIAOの金属シールド面を手前にしたとき、追加GPIOの表面ランドは次の位置にあります。

| 位置 | 追加GPIO |
|---|---|
| 左側D0とD1の間 | D11 |
| 左側D1とD2の間 | D12 |
| 右側D10とD9の間 | D19 |
| 右側D9とD8の間 | D18 |
| 右側D8とD7の間 | D17 |

右側の大きな端子は上から2番目がGND、3番目が3V3です。下端の2列×3個の長方形パッドは今回のGPIOではありません。今回の実装では表面ランドにアクセスできるため、XIAOの取り外しや裏面への配線は不要です。ケース・実装状態によってアクセスしづらい場合は、無理に作業せず開口部を確保します。

写真を追加するまでは、[Seeedの端子図](https://wiki.seeedstudio.com/XIAO_BLE/#xiao-nrf52840-plus-front)と実物の向きを合わせて位置を確認してください。

## 5. はんだ付けする

1. 左右の電源をOFFにし、USBケーブルを抜きます。作業する側のバッテリーコネクタも外します。
2. 仮置きで決めた長さに電線を切り、先端の被覆を必要な分だけ剥きます。
3. ランドと電線を予備はんだし、配線表に沿って1本ずつ接続します。小さいランドを長時間加熱したり、配線を引っ張ったりしないようにします。
4. 各接続の導通と、隣接ランドへのはんだブリッジがないことを確認します。特にVDDとGNDの配線先を再確認します。
5. 配線と基板裏面を絶縁し、ケーブルを仮固定します。ケースを閉じる前に動作確認できる状態にします。

SOはパッドから出る信号なのでXIAOのMISOへ、SIはパッドへ入る信号なのでMOSIへ接続します。左右とも同じ対応です。

## 6. 対応ファームウェアを導入する

標準配布元のUF2には、このフォークのタッチパッド処理が含まれるとは限りません。このリポジトリのActionsで生成した対応UF2を使用します。最新の保存先・ビルドIDは[生成物の保存場所](../docs/generated-output.md)、取得・検証方法は[ファームウェア取得手順](../tools/battery/firmware-tools.md)を参照してください。

1. タッチパッド対応ファームウェアの初回導入では、左右それぞれに対応するUF2を書き込みます。
2. 左右パッド対応版を導入済みで、左のスクロール・スワイプや旧LANG1長押しFnを追加する場合は、左UF2のみ更新します。右UF2とアプリの更新は不要です。
3. UF2を書き込む側をUSB接続し、[書き込み手順](02-FIRMWARE.md)に従います。対応ファームウェアが動いている場合は[Fn+B／Fn+Nによる更新モード移行](../docs/bootloader-keys.md)も利用できます。
4. 書き込み後に左右を起動し、左側をPCへ接続します。右側は左側へBLEで接続します。右パッドを使うために右側をPCへUSB接続する必要はありません。

`settings_reset`は通常の更新では使用しません。Studio保存済みのキー配置が優先される場合は、旧LANG1位置を短押しINT4・長押しFnへ変更するか、Restore Stock Settingsで初期配置を反映します。Restore Stock Settingsでは他の保存済み割り当ても初期化されます。

## 7. 動作確認して固定する

まず左側をPCへUSB接続して確認します。パッドを1個ずつ操作すると、配線と設定の問題を切り分けやすくなります。

- [ ] 通常キー入力と左右の接続が、取り付け前と同じように使える
- [ ] 右パッドでカーソルが動き、上下左右が指の移動方向と合う
- [ ] 左パッドで縦横スクロールできる
- [ ] タップで左クリック、右クリック領域で右クリックできる
- [ ] Fn中も右パッドで上下左右へカーソルが動く
- [ ] Fn中は左パッドの左スワイプで戻る、右スワイプで進む
- [ ] 専用Fn、LANG2長押し、旧LANG1位置の長押しで同じFn操作ができる
- [ ] 電源再投入・左右再接続・放置後の復帰でも動作する
- [ ] PCへのBluetooth接続でも動作する（Bluetoothを使用する場合）

確認できたら最終固定し、ケースで電線を挟んでいないことを確認します。ケースを閉じた後も、キー・パッド・クリックをもう一度確認します。

## 8. 速度・スクロール量を調整する

左側をUSB接続し、`CLEAVE-Battery.exe`のトレイメニューから「タッチパッド設定」を開きます。

- 基本速度・加速の強さ・加速の最大倍率：右パッドのカーソル移動に適用
- Fnスクロール量（アプリ上の項目名）：左の通常時の縦横スクロールに適用
- 検出感度：左右とも1x固定。変更項目はありません

基本速度と最大倍率は0.1倍刻みで調整できます。調整した値はその場で反映され、「キーボードに保存」で再起動後も保持します。未保存の変更は左側の再起動で失われます。USBで保存した設定はPCとのBluetooth接続でも使われます。

範囲・初期値・保存状態の見方は[タッチパッド設定](../tools/battery/trackpad-settings.md)を参照してください。

## 9. うまく動かないとき

| 症状 | 確認すること |
|---|---|
| パッドが反応しない | 対応UF2、VDD・GND、SS・DR・SCK・SO・SIの接続先、導通・ブリッジを確認。右側だけ無反応なら左右間の接続も確認 |
| 左パッドでカーソルが動かない | 現在の仕様では通常時は縦横スクロール。スクロールできる画面で確認 |
| 方向が逆・傾いている | 取り付け方向と軸設定を確認。SPIの配線を入れ替えて方向を直さず、ファームウェア側で調整 |
| 右クリックする場所が違う | 取り付け方向を確認。現在のドライバーでは領域の位置・広さをアプリから指定できない |
| 長押ししてもFnにならない | 200ms以上保持し、Studioに保存されたキー配置を確認。専用Fnでも試す |
| 戻る／進むが出ない | Fnが有効か、横方向へ十分動かしているか確認。対応ブラウザーで履歴を作って試す |
| 設定の反映待ちが続く | 左USB接続、右電源、左右接続、対応ファームウェアを確認。右センサーの応答がない場合は保存できない |
| 再起動すると調整値が戻る | アプリで反映を確認して「キーボードに保存」を実行したか確認 |

配線を修正するときは、USBとバッテリーを外してから作業します。
