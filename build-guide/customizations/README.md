# CLEAVE HHJP カスタマイズ記録

自分のCLEAVE HHJPに加えた変更と、現在の使い方を残すための記録。実装した順番ではなく、確認したい内容ごとにまとめる。組み立て手順を一から説明するガイドにはしない。

元のビルドガイドの00〜05とは分け、このフォルダーに独自の変更を置く。

| 記録 | 内容 |
|---|---|
| [ハードウェア](hardware.md) | 左右のTM040040、配線とケーブル色、薄型ケースのSTL |
| [キー配置](keymap.md) | LANGキーのFn兼用、クリック、接続切替、マクロとレイヤー |
| [トラックパッド](trackpad.md) | 左右の役割、タップと端スクロール、速度・加速・スクロール量 |
| [設定・電源・更新](system.md) | DYA Studio、設定保存、スリープ、バッテリーとUF2更新 |

現在は左右にパッドを取り付け、右をカーソル移動、左を縦横スクロールに使用。設定変更にはDYA Studioを使う。以前のマウスレイヤーと独自Windowsアプリは廃止した。

写真は後で追加する。細かなソース構成は[ファームウェア設計](../../docs/firmware_design.md)、ビルド成果物の所在は[生成物の保存場所](../../docs/generated-output.md)を参照。
