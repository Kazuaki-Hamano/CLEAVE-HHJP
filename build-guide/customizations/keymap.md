# キー配置

[カスタマイズ記録](README.md)

## Fnの押し方

初期キーマップの定義は[cleave_hhjp.keymap](../../config/cleave_hhjp.keymap)。通常のDefaultとFnの2レイヤーが基本。マウスレイヤーは削除済み。

| キー位置 | 短押し | 長押し |
|---|---|---|
| 左のLANG2位置 | INT5 | Fn |
| 右の旧LANG1位置（Spaceの隣） | INT4 | Fn |
| 左右の専用Fn | 押している間Fn | 同じ |

LANGキーの判定時間は200ms、tap-preferred。短押しは現在の実装ではINT4／INT5を送るため、実際の言語切替はOSとIMEの割り当てによる。独立したKanaキーはLANG1を送る。

## 追加した操作

| 操作 | 動作 |
|---|---|
| Fn＋Q | マウス左ボタン。押している間保持 |
| Fn＋E | マウス右ボタン。押している間保持 |
| Fn＋U | DYA StudioのBLE検出用広告を60秒間有効化 |
| Fn＋Bを2秒長押し | 左側をUF2モードへ |
| Fn＋Nを2秒長押し | 右側をUF2モードへ |

Fn＋B／Nの短押しはB／PLUS。

右パッドはFn中もカーソル移動できる。Fn＋Qを保持してパッドを動かし、Qを離してドロップする。Fn中の左パッドは[戻る／進む](trackpad.md)に使う。

## 元からある接続切替操作

以下は独自に追加した機能ではなく、元のキーマップから引き継いだ操作。

| 操作 | 動作 |
|---|---|
| Fn＋Ctrl＋1〜5 | Bluetoothプロファイル0〜4を選択 |
| Fn＋Ctrl＋Backspace | 現在のプロファイルのペアリングを消去 |

Fn＋1〜5だけならF1〜F5、Fn＋BackspaceはDelete。

## DYAで編集するもの

キー配置、マクロ、コンボ、追加レイヤーはDYA Studioから変更できる。Runtime Macroは内容を保存した後、キーにスロットを割り当ててキー配置も保存する。マクロ割り当てと実行は実機確認済み。

追加レイヤー用に4枠を確保しているが、初期状態では無効。接続先・OS別の既定レイヤーの対応も初期状態では未設定。使う場合は通常用レイヤーを追加し、対応先を設定する。Fnを既定レイヤーにはしない。レイヤーの並べ替え後は対応先も確認する。

保存済みのキー配置は、ファームウェア内の初期配置より優先される。ビルドし直した配置がそのまま出るとは限らない。初期配置に戻す場合のRestore Stock Settingsは、保存した配置を戻す操作として扱う。

編集・接続の詳細は[DYA Studio](../../docs/dya-studio.md)、UF2移行の詳細は[ブートローダー操作](../../docs/bootloader-keys.md)を参照。
