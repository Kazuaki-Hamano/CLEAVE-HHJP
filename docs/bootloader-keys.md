# キー操作でUF2書き込みモードへ移行

| 対象 | 操作 | 短押し時の動作 |
|---|---|---|
| 左の親機 | Fnを押しながら、左のZキーを2秒長押し | Z |
| 右の子機 | Fnを押しながら、右の\_キー（INT1、0x70087）を2秒長押し | INT1（0x70087） |

Fnは専用Fnキー、または左右のLANG兼用キーの長押しで有効にします。
右側は記号の入力ではなく、DefaultレイヤーのINT1位置を押します。
USBを更新する側につないだ状態で操作し、UF2ドライブが表示されたら
FnとZ/\_を離して、その側に対応するUF2をコピーしてください。
2秒未満で離した場合は書き込みモードへ入りません。

初回だけは従来どおりリセットボタンを2回押し、今回のUF2を左右へ
書き込む必要があります。右側のキー操作も親機経由で処理するため、
右側を試すときは左右とも通常動作・接続した状態にしてください。
両側を更新する場合は、右→左の順が使いやすいです。

ZMK Studioに保存したキーマップがある場合は、保存済み配置が優先される
ことがあります。新しい割り当てが効かない場合は、Studioの保存済み配置を
確認してください。設定全消去・settings_resetは通常の更新には不要です。

実機確認：左の操作で左のUF2ドライブ、右の操作で右のUF2ドライブが
表示されることを確認します。短押しのZ/INT1、通常入力、マウス操作、
残量・充電状態表示も確認してください。

実装はtap-preferredのhold-tapから標準`&bootloader`を呼びます。
割り当て元の左右情報を保持し、コンボは使いません。
ZMK v0.3では`RST_UF2=0x57`をGPREGRETへ保存して再起動します。
