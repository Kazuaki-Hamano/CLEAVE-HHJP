# TM040040-2024-302 組み込み

取り付け作業は[TM040040タッチパッド取り付けガイド](../build-guide/06-TRACKPAD.md)を参照してください。この文書では配線とドライバー実装の詳細を扱います。

対象: CLEAVE HHJP、XIAO nRF52840 Plus、ZMK v0.3-branch。
基本操作の対応版は`502000da`（UF2内ビルドID `c5177ebb`）。左パッドのスクロール・Fnスワイプ、旧LANG1位置の短押しINT4・200ms長押しFnに加え、Fn中の右カーソル移動とFn＋Q/Eの左右クリックに対応します。ビルド・生成DTS・UF2・判定処理を検証済みで、新しい操作は実機確認待ちです。左右パッドの通常動作は追加版`a281e739`（`e2b99f43`）でユーザー確認済みです。設定反映・保存・再起動後の保持も確認されています。今回の変更は左UF2の書き込みだけで利用でき、アプリと右UF2の更新は不要です。操作は[設定ガイド](../tools/battery/trackpad-settings.md)を参照してください。

## 配線

左右それぞれのXIAOへ、同じ端子割り当てで接続します。次の色は右側用です。

| 色 | パッドのランド | XIAO | GPIO |
|---|---|---|---|
| 黒 | GND | GND | — |
| 赤 | VDD | 3V3 | — |
| 茶 | SS | D11 | P0.15 |
| 橙 | DR | D12 | P0.19 |
| 黄 | SCK | D17 | P1.03 |
| 緑 | SO / MISO | D18 | P1.05 |
| 青 | SI / MOSI | D19 | P1.07 |

左側のケーブル色は以下です。

| 色 | パッド端子 | 左XIAO |
|---|---|---|
| 黒 | GND | GND |
| 白 | VDD | 3V3 |
| 灰 | SS / CS | D11 |
| 紫 | DR | D12 |
| 黄 | SCK | D17 |
| 緑 | SO / MISO | D18 |
| 青 | SI / MOSI | D19 |

VDDは2.5～3.6V仕様。5V/VBUSやBAT+には接続しません。SPI用R1は外しません。B1/B2/B3、SCL/SDA、FFCコネクタは使いません。

USB端子を上、シールド面を手前にしたXIAOの表面では、左側D0/D1間がD11、D1/D2間がD12、右側D10/D9間がD19、D9/D8間がD18、D8/D7間がD17です。右側の大きな端子の上から2番目がGND、3番目が3V3。下端の2列×3個の長方形パッドは今回のGPIOではありません。裏面への配線やXIAOの取り外しは不要です。

## ファームウェア

- [petejohanson/cirque-input-module](https://github.com/petejohanson/cirque-input-module)の`0de55f36bc720b5be3d8880dc856d4d78baf5214`を基に、実行時の感度変更を追加したドライバーを`src/pinnacle/`へ取り込みました。外部west依存は削除しました。
- 右側の`Kconfig.defconfig`で`ZMK_POINTING`と`SPI`を有効化。現行ビルドでは共通の`cleave_hhjp.conf`は左右どちらにも読み込まれません。左側は`cleave_hhjp_left.conf`を読み込みます。
- 右overlayの`spi2`を追加GPIOに割り当て、1MHzのSPI、CS active-low、DR active-highで読み取ります。キーのD0～D10、P0.09、P0.10は変更しません。
- 共通`cleave_hhjp_trackpad.dtsi`に`zmk,input-split`（ID 0）を定義。右側の実デバイス→左右間BLE→左側listener→USB/BLEのマウスレポートという経路です。
- 左側にもローカルのSPIパッドと専用listenerを追加しました。SPI設定は`cleave_hhjp_trackpad_spi.dtsi`を左右で共有し、左右それぞれでD11・D12・D17～D19を使用します。左パッドの入力はBLE転送せず、左側で直接処理します。
- 左は通常時に縦横スクロール、Fn中に左スワイプで戻る・右スワイプで進むです。右はFn中もカーソル移動です。スクロール量の設定は左パッドへ適用し、端数は軸ごとに独立しています。速度・加速は右カーソルへ適用します。左側も1x固定、タップクリック有効で、向きは右側と同じ`y-invert`です。両パッドの通常動作はユーザー確認済みで、今回のスクロール・スワイプは実機確認待ちです。
- 初回導入は左右両方のUF2を更新してください。標準split設定同期に対応した`5fedfa36`から現行のスクロール量設定へ移行する場合は、左側とアプリのみの更新でも利用できます。
- 右は通常時のカーソル移動、左右ともタップクリックを有効化。`no-taps`と`no-secondary-tap`を指定しないことで、通常タップとチップ内蔵の右クリック領域を利用します。領域は標準方向の右上で、現ドライバーに位置・広さの指定項目はありません。今回の取り付け方向では右下端の右クリックを実機確認済みです。`sensitivity = "1x"`、`sleep`、`y-invert`を指定。
- ユーザーが通常タップの左クリックと右下端の右クリックを確認済み。
- Mouseレイヤーと専用速度処理を削除。旧LANG1位置は短押しINT4・200ms長押しFnです。LANG2長押しと同じFnレイヤー1を使います。
- 右パッドはFn中もカーソルを動かします。Fnクリックキーとの併用でドラッグするため、旧Fn縦スクロール切り替えを削除しました。スクロールには左パッドを使用します。
- 基本速度・加速の強さ・最大倍率・Fnスクロール量をアプリから変更し、左側へ保存できます。検出感度は1x固定です。操作手順・範囲・初期値・実機確認項目は[タッチパッド設定](../tools/battery/trackpad-settings.md)を参照してください。速度・加速とFnスクロールは別に処理します。

## 検証

### 放置後の復帰時間の比較

放置後のパッド復帰に2～3秒掛かるとの実機報告を受け、Sleep Interval（レジスター`0x0C`）を255から50へ変更して比較します。左右共通のドライバー初期化で設定します。サンプル頻度、Sleep Timer、Sleep有効設定、感度、カーソル・クリック・スクロール処理は変更しません。復帰時間の改善は未確認です。

左右を更新し、パッドがスリープするまで触らずに待ってから、最初の操作が出るまでの時間を左右別々に確認してください。キー入力の復帰も遅いか、パッドだけ遅いかも切り分けます。倍率設定と保存済みキー配置は通常のUF2更新で維持し、アプリ更新や設定リセットは不要です。

### 右パッドのチップ内蔵スクロール（正式採用）

試用版は`f0c97f61`（埋込ビルドID `9f996f58`、[Actions Run 38973716605](https://github.com/Kazuaki-Hamano/CLEAVE-HHJP/actions/runs/38973716605)）。左右ビルド・UF2・生成DTSの右側のみ有効化を検証済みです。`502000da`からは右UF2のみ更新し、左とアプリはそのまま使用できます。戻す場合は右に`502000da`を書き戻します。

右overlayの`native-scroll`で、Intellimouse相対パケットの4バイト目を符号付き8bitの縦ホイール値として転送します。FeedConfig2のIntellimouse有効・Scroll Disable解除は従来から設定済みですが、旧ドライバーは3バイトしか読まないためホイール値を送っていませんでした。現在は4バイト読み、右側だけホイール値を報告します。左側はこのプロパティを指定せず、従来の縦横スクロール・Fnスワイプを維持します。

右端を上下になぞる内蔵スクロールは実機確認済みで正式採用しました。右の内蔵ホイール値は左セントラルで専用倍率を掛けます。アプリの「右端スクロール量」で0.1～4.0倍を0.1倍刻みで変更でき、1.0倍がチップの出力と同量です。カーソル速度・加速は掛けません。左スクロール量とも独立しています。Fn中のカーソル移動とFn＋Q/Eクリックは維持します。倍率変更には左UF2とアプリの更新が必要です。

公式資料のFeedConfig2と相対パケット表はホイールデータ形式を説明していますが、スクロールが発動する指の動きや領域の詳細は説明していません。端に沿った上下操作などで実際の発動位置・方向・量と通常カーソル操作への影響を確認します。二本指・円周スクロールを実装したものではありません。右端上下での発動と操作感は実機確認済みです。新しい倍率設定の実機反映は別途確認します。

仕様：[Interfacing to the Pinnacle ASIC Using SPI and I2C](https://www.mouser.com/pdfDocs/InterfaceSPIandI2C.pdf)の9～10ページ。

ビルド後、左右それぞれの生成DTS・Kconfig、Pinnacleドライバーとinput-splitのリンク、UF2識別子を確認します。

実機では次を確認してください。

1. 左右を更新して再起動し、通常キーと左右の接続を確認。
2. 右パッドのカーソル移動と、左パッドの縦横スクロールの方向を確認。
3. 通常領域のタップで左クリック、右下端で右クリックを確認。Fn中は右パッドがカーソル移動、左パッドが左スワイプで戻る・右スワイプで進むとなることを確認。LANG2・旧LANG1位置の長押しと専用Fnで同じ動作になることも確認。
4. USB接続と、使用する場合はPCへのBluetooth接続を確認。
5. 放置後の復帰、左右の電源再投入・再接続を確認。

ビルド成功と実機動作確認は別です。未接続時の継続動作、向き、感度、消費電力は実機で評価します。
